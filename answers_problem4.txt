練習問題4：生成と消去　解答と解説
================================================================


問題 4-1　コンストラクタとメモリの解放
------------------------------------------------------------------
【解答】
// number.h
#ifndef NUMBER_H
#define NUMBER_H

class Number{
private:
    //    メンバ変数
    int a;
    int b;
public:
    //    コンストラクタ
    Number();
    //    二つの数値を設定
    void setNumbers(int n1, int n2);
    //    二つの数の和を取得
    int getAdd();
};

#endif // NUMBER_H

// number.cpp
#include "number.h"

//    コンストラクタ（メンバ変数を0で初期化）
Number::Number() : a(0), b(0)
{
}
//    二つの数値を設定
void Number::setNumbers(int n1, int n2)
{
    a = n1;
    b = n2;
}
int Number::getAdd()
{
    return a + b;
}

// main.cpp
#include <iostream>
#include "number.h"

using namespace std;

int main(){
    Number* pN;
    pN = new Number();
    pN->setNumbers(1, 2);
    cout << pN->getAdd() << endl;
    //    メモリを解放する
    delete pN;
    return 0;
}

【解説】
コンストラクタは、クラス名と同じ名前で、戻り値の型を書かない特別なメンバ関数です。
インスタンスが生成されるときに自動的に呼び出されるので、メンバ変数の初期化に使います。
ここでは、「: a(0), b(0)」という初期化子リストで a と b を 0 に初期化しています。
コンストラクタの中で a = 0; b = 0; と代入しても、結果は同じです。
new で確保したメモリは、使い終わったら delete で解放します。
解放しないと、プログラムの実行中にメモリが確保されたままになります（メモリリーク）。


================================================================
問題 4-2　コンストラクタとデストラクタの追加
------------------------------------------------------------------
【解答】
// hoge.cpp
#include "hoge.h"
#include <iostream>

using namespace std;

//    コンストラクタ
Hoge::Hoge()
{
    cout << "コンストラクタ" << endl;
}
//    デストラクタ
Hoge::~Hoge()
{
    cout << "デストラクタ" << endl;
}
void Hoge::foo()
{
    cout << "fooメソッド" << endl;
}

（hoge.h、main.cpp は問題文のまま。変更なし）

【解説】
コンストラクタとデストラクタは hoge.h ですでに宣言されているので、
hoge.cpp に処理の中身を書くだけで完成します。
  ・コンストラクタ Hoge::Hoge()  ：new Hoge() でインスタンスが生成されるときに呼ばれる
  ・デストラクタ   Hoge::~Hoge() ：delete pH でインスタンスが消去されるときに呼ばれる
そのため、実行結果は「コンストラクタ → fooメソッド → デストラクタ」の順になります。
デストラクタは、クラス名の前に ~（チルダ）を付けた名前で、引数も戻り値もありません。


================================================================
問題 4-3　配列のメモリの解放
------------------------------------------------------------------
【解答】
#include <iostream>

using namespace std;

int main(){
    //    配列を生成
    int* num = new int[4];
    int i;
    //    配列に値を代入
    for (i = 0; i < 4; i++){
        num[i] = i;
    }
    //    配列の内容を表示
    for (i = 0; i < 4; i++){
        cout << "num[" << i << "]=" << num[i] << " ";
    }
    cout << endl;
    //    配列のメモリを解放
    delete[] num;
    return 0;
}

【解説】
new 型名[要素数] で確保した配列は、delete ではなく delete[] で解放します。
delete[] を使うと、配列の全要素の分のメモリが正しく解放されます。
（配列に delete を使った場合の動作は未定義で、正しく解放される保証はありません）
new と delete、new[] と delete[] は、必ず対にして使うようにしましょう。
