開発環境：Visual Studio 2026

Windows で C++ のプログラムを作成・実行する

トップページ › 開発環境：Visual Studio 2026

Visual Studio とは

Visual Studio の特徴

Visual Studio は、Microsoft が開発している Windows 用の統合開発環境（IDE）です。エディタ・コンパイラ・デバッガがひとつにまとまっているので、インストールするだけで C++ のプログラムを作成・実行できます。

個人の学習用途であれば、無料の Visual Studio Community エディションを利用できます。このページでは、Visual Studio 2026 Community を使って、このサイトのサンプルプログラムを動かす手順を説明します。

💡 画面の文言やメニューの位置は、Visual Studio のバージョンや更新によって多少変わることがあります。ほかのバージョン（Visual Studio 2022 など）でも、手順はほぼ同じです。

インストール

Step 1

以下の公式サイトから、Visual Studio Community のインストーラーをダウンロードします。

Visual Studio 公式サイト：https://visualstudio.microsoft.com/ja/

Step 2

ダウンロードしたインストーラーを実行します。「ワークロード」の選択画面が表示されたら、C++ によるデスクトップ開発 にチェックを入れて、［インストール］ボタンをクリックします。

⚠️ 「C++ によるデスクトップ開発」 を選ばずにインストールすると、C++ のプロジェクトを作成できません。あとから追加する場合は、スタートメニューから Visual Studio Installer を起動し、［変更］から同じワークロードを追加してください。
Step 3

インストールが完了したら Visual Studio を起動します。初回はサインインを求められますが、Microsoft アカウントを持っていない場合は、あとでサインインすることもできます。

プロジェクトの作成

空のプロジェクトを作る

Visual Studio では、プログラムを プロジェクト という単位で管理します。このサイトのサンプルを試すときは、サンプルごとにプロジェクトを作るのがおすすめです。

Step 1

起動画面で 新しいプロジェクトの作成 をクリックします（すでに Visual Studio を開いている場合は、メニューの ファイル → 新規作成 → プロジェクト）。

Step 2

言語の絞り込みで C++ を選び、テンプレートの一覧から 空のプロジェクト を選んで［次へ］をクリックします。

Step 3

「プロジェクト名」に名前（例：Sample101）を入力し、保存場所を確認して［作成］をクリックします。

💡 「コンソールアプリ」テンプレートを選ぶと、Hello World を表示するソースファイルが最初から用意されたプロジェクトができます。このサイトのサンプルを入力する場合は、中身を書き換えて使ってください。

ソースファイルを追加する

Step 1

画面右側の ソリューションエクスプローラー で、ソースファイル フォルダーを右クリックし、追加 → 新しい項目 を選びます。

Step 2

C++ ファイル (.cpp) を選び、名前を main.cpp にして［追加］をクリックします。

Step 3

エディタに、次のようなプログラムを入力します。

main.cpp
#include <iostream>

using namespace std;

int main(){
    cout << "HelloWorld." << endl;
    return 0;
}

ヘッダファイルやクラスを追加する

2日目以降のサンプルでは、sample.h・sample.cpp・main.cpp のように、ひとつのプログラムを複数のファイルに分けて作ります。

  • ヘッダファイル（.h）：ヘッダーファイル フォルダーを右クリックし、追加 → 新しい項目 → ヘッダーファイル (.h) を選びます。
  • ソースファイル（.cpp）：ソースファイル フォルダーに、main.cpp と同じ手順で追加します。

同じプロジェクトに追加したファイルは、ビルドのときにまとめてコンパイル・リンクされます。

ビルドと実行

デバッグなしで実行する

プログラムを入力したら、メニューの デバッグ → デバッグなしで開始（ショートカット Ctrl + F5）を選びます。ビルドが成功すると、コンソール画面（ウィンドウ）が開いて実行結果が表示されます。

実行結果
HelloWorld.

デバッグ → デバッグの開始（F5）を選ぶと、ブレークポイントで止めながら、1行ずつ動きを確かめられます。

エラーが出たとき

文法の誤りがあると、ビルドに失敗し、画面下部の エラー一覧 にエラーの内容と行番号が表示されます。エラーをダブルクリックすると、該当する行に移動できます。表示された行と、その前後の行を確認して修正しましょう。

⚠️ 日本語が文字化けする場合：ソースファイルの文字コードが原因のことがあります。メニューの ファイル → 名前を付けて保存 で、［保存］ボタン横の▼から エンコード付きで保存 を選び、Unicode (UTF-8 シグネチャ付き) で保存し直してから、もう一度実行してみてください。
