================================================================
練習問題1：名前空間　解答と解説
================================================================


問題 1-1　coutによる文字列の表示
------------------------------------------------------------------
【解答】
#include <iostream>

using namespace std;

int main(){
    cout << "C++" << endl;
    return 0;
}

【解説】
cout は、<< 演算子で渡した値をコンソールに出力します。
endl は改行を出力するとともに、出力バッファの内容を画面に送り出します（フラッシュ）。
cout と endl は名前空間 std に属しているので、using namespace std; を書いておくと、
std:: を付けずに使うことができます。


================================================================
問題 1-2　usingを使わない書き方
------------------------------------------------------------------
【解答】
#include <iostream>

int main(){
    std::cout << "programming in C++ Language" << std::endl;
    return 0;
}

【解説】
using namespace std; を削除すると、cout や endl を名前空間の名前なしでは使えなくなります。
その場合は、スコープ解決演算子 :: を使って std::cout、std::endl のように、
所属する名前空間を明示して書きます。
大きなプログラムやヘッダファイルでは、名前の衝突を避けるために、
using namespace std; を使わずに std:: を付けて書くことも多くあります。


================================================================
問題 1-3　coutを1つにまとめる
------------------------------------------------------------------
【解答】
#include <iostream>

using namespace std;

int main(){
    cout << "ONE TWO THREE" << endl << "FOUR FIVE SIX" << endl;
    return 0;
}

【解説】
cout は << 演算子を続けて書くことで、複数の値を1行の処理で順に出力できます。
1行目の文字列の後に endl をはさみ、続けて2行目の文字列と endl を出力すれば、
元のプログラムと同じ結果が得られます。
（改行文字 "\n" を使って cout << "ONE TWO THREE\nFOUR FIVE SIX" << endl; と書くこともできます）


================================================================
問題 1-4　入力した数値を2倍にする
------------------------------------------------------------------
【解答】
#include <iostream>

using namespace std;

int main(){
    int n;
    cout << "数値を入力してください:";
    cin >> n;
    cout << n << "を2倍した数は、" << n * 2 << "です。" << endl;
    return 0;
}

【解説】
cin は、>> 演算子でキーボードから入力された値を変数に読み込みます。
読み込み先の変数が int 型なので、入力された文字列は自動的に整数に変換されます。
C言語の scanf() と違い、書式指定や変数のアドレス（&）を書く必要はありません。
計算結果 n * 2 は、そのまま cout に渡して出力できます。


================================================================
問題 1-5　2つの整数の和と差
------------------------------------------------------------------
【解答】
#include <iostream>

using namespace std;

int main(){
    int a, b;
    cout << "1つ目の数:";
    cin >> a;
    cout << "2つ目の数:";
    cin >> b;
    cout << a << " + " << b << " = " << a + b << endl;
    cout << a << " - " << b << " = " << a - b << endl;
    return 0;
}

【解説】
2つの整数を、それぞれ cin で別の変数に読み込みます。
出力では、数値と文字列（" + " や " = "）を << でつなげて1行にまとめています。
a + b や a - b のような式も、そのまま cout に渡すことができます。


================================================================
問題 1-6　stringによる姓と名の結合
------------------------------------------------------------------
【解答】
#include <iostream>
#include <string>

using namespace std;

int main(){
    string lastName, firstName;
    cout << "姓を入力:";
    cin >> lastName;
    cout << "名を入力:";
    cin >> firstName;
    //    + 演算子で姓と名を連結する
    string name = lastName + firstName;
    cout << "名前は「" << name << "」です。" << endl;
    return 0;
}

【解説】
文字列を扱うには、ヘッダファイル <string> をインクルードして string 型を使います。
string 型の変数は、cin で直接読み込むことができ、+ 演算子で連結できます。
C言語の文字配列と違い、配列の大きさや strcat() による連結を気にする必要はありません。


================================================================
問題 1-7　ビルドエラーの修正
------------------------------------------------------------------
【解答】
#include <iostream>

using namespace std;

int main(){
    cout << "HelloWorld." << endl;
    return 0;
}

【解説】
元のプログラムには using namespace std; がないため、cout と endl が見つからず、
「識別子 "cout" が定義されていません」のようなビルドエラーになります。
using namespace std; を追加するか、std::cout、std::endl と書けば解決します。
また、main() 関数の最後には return 0; を書いておきましょう。
（main() に限っては省略しても 0 を返したことになりますが、明示したほうが読みやすくなります）
