型の変換とキャスト

C言語のキャスト

ある型の値を別の型に変換することをキャスト（型変換）と言います。C言語では、(double)a のように、変換したい型を () で囲んで値の前に書きました。この書き方は C++ でも使えますが、次のような問題があります。

  • 何でも変換できてしまう：数値の変換のような安全な変換も、ポインタを無関係な型に変えるような危険な変換も、同じ書き方でできてしまいます。誤った変換をしても、コンパイラはエラーにしません。
  • 目立たない：() は式の中によく出てくるので、プログラムのどこでキャストしているのかを探しにくくなります。

C++のキャスト

そこで C++ では、目的ごとに分けた4種類のキャスト演算子が用意されています。

C++のキャストの書式
static_cast<変換後の型>(値)
表S4-1：C++のキャスト演算子
キャスト用途
static_cast数値の型の変換など、一般的で安全な変換
dynamic_cast継承関係にあるクラスのポインタ・参照の変換（実行時に確認する）
const_castconst を外す変換
reinterpret_castポインタを無関係な型に変換するなど、危険な変換

目的を指定して変換するので、意図しない危険な変換はコンパイラがエラーにしてくれます。また、名前が長く目立つので、プログラムのどこでキャストしているかがすぐにわかります。

static_cast

サンプルプログラム

最もよく使うのが static_cast です。数値の型どうしの変換などに使います。

lists4-1：main.cpp
#include <iostream>

using namespace std;

int main(){
    int total = 238;
    int count = 3;
    //    整数どうしの割り算は、小数点以下が切り捨てられる
    cout << "int / int    ：" << total / count << endl;
    //    static_castでdouble型に変換してから割る
    cout << "static_cast  ：" << static_cast<double>(total) / count << endl;
    //    小数を整数に変換する（小数点以下は切り捨て）
    double price = 1980.75;
    int yen = static_cast<int>(price);
    cout << "整数への変換 ：" << yen << endl;
    //    文字と文字コードの変換
    char c = 'A';
    cout << "'A'の文字コード：" << static_cast<int>(c) << endl;
    cout << "66番の文字  ：" << static_cast<char>(66) << endl;
    return 0;
}
実行結果
int / int ：79
static_cast ：79.3333
整数への変換 ：1980
'A'の文字コード：65
66番の文字 ：B

数値の型の変換

9行目のように int 型どうしで割り算をすると、結果も int 型になり、小数点以下が切り捨てられます。11行目では、total を static_cast で double 型に変換してから割っているので、小数点以下まで計算されます。平均値を求めるときによく使う書き方です（補講2の lists2-3 でも使っています）。

14行目は、double 型を int 型に変換しています。小数点以下は切り捨てられます。このような、情報が失われる可能性のある変換は、キャストを書かなくても行われることがありますが、コンパイラが警告を出すことがあります。static_cast で明示すれば、「意図して変換している」ことがはっきりします。

18行目・19行目は、文字（char 型）と文字コード（int 型）の変換です。'A' の文字コードは 65 で、66 は 'B' に対応します。

dynamic_cast

親クラスのポインタから子クラスへ

応用編6日目で学んだように、親クラスのポインタには、子クラスのオブジェクトのアドレスを入れられます。仮想関数を使えば、親クラスのポインタのままで、子クラスごとに異なる処理を呼び出せました。

しかし、子クラスにしかないメンバ関数は、親クラスのポインタからは呼び出せません。そのような場合に、親クラスのポインタを子クラスのポインタに変換するのが dynamic_cast です。

サンプルプログラム

応用編6日目の鳥のクラスを使った例です。Chicken（ニワトリ）クラスにだけ、卵を産む layEgg() があります。

lists4-2：main.cpp
#include <iostream>

using namespace std;

//    鳥クラス（仮想関数を持つ）
class Bird{
public:
    virtual ~Bird(){}
    virtual void sing() = 0;
};

//    カラスクラス
class Crow : public Bird{
public:
    void sing(){ cout << "カーカー" << endl; }
};

//    ニワトリクラス（卵を産む機能を持つ）
class Chicken : public Bird{
public:
    void sing(){ cout << "コケコッコー" << endl; }
    void layEgg(){ cout << "卵を産みました" << endl; }
};

int main(){
    Bird* birds[] = { new Crow(), new Chicken(), new Crow() };
    for (int i = 0; i < 3; i++){
        birds[i]->sing();
        //    Chickenのときだけ、layEgg()を呼び出す
        Chicken* ch = dynamic_cast<Chicken*>(birds[i]);
        if (ch != nullptr){
            ch->layEgg();
        }
    }
    for (int i = 0; i < 3; i++){
        delete birds[i];
    }
    return 0;
}
実行結果
カーカー
コケコッコー
卵を産みました
カーカー

dynamic_cast の働き

30行目で、Bird 型のポインタ birds[i] を、dynamic_cast で Chicken 型のポインタに変換しています。dynamic_cast は、実行時に、ポインタが指しているオブジェクトの本当の型を調べます。

  • 指しているのが Chicken のオブジェクトなら、Chicken 型のポインタが返されます。
  • 指しているのが Crow のオブジェクトなら、変換できないので、nullptr（どこも指していないことを表すポインタ。NULL と同じ意味）が返されます。

そのため、31行目のように結果が nullptr でないことを確認してから使えば、Chicken のときだけ layEgg() を呼び出せます。

dynamic_cast によるポインタの変換
子クラス名* 変数名 = dynamic_cast<子クラス名*>(親クラスのポインタ);
⚠️ dynamic_cast は、仮想関数を1つ以上持つクラスでしか使えません。このサンプルの Bird クラスは、仮想デストラクタ（8行目）と純粋仮想関数（9行目）を持っているので使えます。
💡 dynamic_cast を何度も使って型ごとに処理を分けるのは、あまりよい設計ではありません。本来は、各クラスに共通の仮想関数を用意して、ポリモーフィズムで処理を切り替えるのが基本です。dynamic_cast は、どうしても子クラス特有の機能が必要な場合に使いましょう。

子クラスから親クラスへの変換

逆に、子クラスのポインタを親クラスのポインタに変換する場合は、キャストは必要ありません。26行目で、new Crow() の結果（Crow 型のポインタ）を Bird 型のポインタの配列にそのまま入れているように、自動的に変換されます。応用編6日目の listex6-3 でも、Sample のポインタを foo(s); のようにそのまま渡すだけで、インターフェース IInf1 のポインタとして受け取れています。

その他のキャスト

const_cast と reinterpret_cast

const_cast は、const 修飾子を外すためのキャストです。const 修飾子は「値を変更しない」ことを保証するものなので（応用編2日目参照）、それを外すのは本来避けるべきことです。const に対応していない古い関数に値を渡すときなど、限られた場面でしか使いません。

reinterpret_cast は、ポインタを無関係な型のポインタや整数に変換するなど、メモリの中身の「解釈」を変える危険なキャストです。ハードウェアを直接扱うような特殊なプログラム以外では、使うことはほとんどありません。

キャストのまとめ

  • C言語のキャスト (型)値 は使わず、目的に合った C++ のキャストを使う。
  • 数値の変換など、普段の変換には static_cast を使う。
  • 親クラスのポインタを子クラスのポインタに変換するときは、dynamic_cast を使い、結果が nullptr でないかを確認する。
  • const_cast と reinterpret_cast は、できるだけ使わない。キャストが必要になったら、まず設計を見直せないかを考える。
