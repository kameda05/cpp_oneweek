# 図の生成スクリプト

サイトの図（`img/fig*.svg`、38 枚）は、このフォルダの Python スクリプトで生成しています。
図を直すときは SVG を直接編集せず、スクリプトを直して生成し直してください。

このフォルダはサイトの公開には不要です。サーバーにはアップロードしないでください。

## ファイル

| ファイル | 内容 |
|---|---|
| `figs_classes.py` | 共通部品（`Svg` クラス、ファイル形・UML クラス図・吹き出しの描画）と、クラス名を含む図 10 枚 |
| `figs_others.py` | それ以外の図 28 枚と、イラスト（自動車・鳥など）の描画部品 |

各図は `fig5_1()` のような関数 1 つに対応しており、関数名の `_` を `-` に置き換えたものがファイル名になります（`fig5_1()` → `img/fig5-1.svg`）。

## 使い方

Python 3 があれば動きます（追加のライブラリは不要です）。プロジェクトのフォルダで次のように実行すると、`img/` に SVG が書き出されます。

```
python tools/figs_classes.py
python tools/figs_others.py
```

それぞれ、そのファイルで定義している図をすべて書き出します（既存のファイルは上書きされます）。
出力先を変えたいときは、引数でフォルダを指定します（例：`python tools/figs_others.py tmp`）。

## 書き方のメモ

- 座標の単位はピクセルで、左上が原点です。図の大きさは各関数の最初の `Svg(幅, 高さ)` で決まります。
- 色は `INK`（黒）、`RED`（赤）、`BLUE`（青）を使います。
- 矢印は `arrow='a'`（黒）、`'ar'`（赤）、`'ab'`（青）、`'tri'`（継承を表す白抜きの三角）で指定します。
- 文字は `s.text(x, y, 文字列, 大きさ, 揃え)` で書きます。`mono=True` でコード用の等幅フォントになります。
- 生成した図は、ブラウザで開いて文字の重なりや切れがないか確認してください。
