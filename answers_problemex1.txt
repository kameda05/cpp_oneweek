問題 1-1　参照を使った値の変更
------------------------------------------------------------------
【解答】
#include <iostream>

using namespace std;

int main(){
    int a = 7;
    int &n = a;
    cout << "a = " << a << endl;
    //    参照nを通して、aの値に3を足す
    n += 3;
    cout << "a = " << a << endl;
    return 0;
}

【解説】
int &n = a; と書くと、n は変数 a の参照（別名）になります。
n と a は同じメモリ領域を指しているので、n += 3; のように n の値を変えると、
a の値も変わります。そのため、a に直接手を触れずに a の値を 10 にできます。


================================================================
問題 1-2　ポインタ渡しから参照渡しへ
------------------------------------------------------------------
【解答】
#include <iostream>

using namespace std;

void changeNumber(int&);

int main(){
    int n = 5;
    cout << "変更前 : " << n << endl;
    changeNumber(n);
    cout << "変更後 : " << n << endl;
    return 0;
}

void changeNumber(int& n){
    n *= 2;    //    数値を2倍にする
}

【解説】
引数の型を int* から int& に変えると、参照渡しになります。
参照渡しでは、呼び出し側は changeNumber(n) のように変数をそのまま渡し、
関数の中でも *n ではなく n と、通常の変数と同じように書けます。
関数内で n を変更すると、呼び出し元の変数 n も変更されます。
ポインタと違い、アドレス演算子 & や間接参照演算子 * を書く必要がないので、
読みやすく、誤りも少なくなります。


================================================================
問題 1-3　参照渡しによるswap関数
------------------------------------------------------------------
【解答】
#include <iostream>

using namespace std;

void swap(int&, int&);

int main()
{
    int a = 1, b = 2;
    cout << "a = " << a << " b = " << b << endl;
    swap(a, b);
    cout << "a = " << a << " b = " << b << endl;
    return 0;
}

void swap(int& a, int& b)
{
    int tmp;
    tmp = a;
    a = b;
    b = tmp;
}

【解説】
問題1-2と同じく、引数を参照（int&）に変えれば、関数の中で呼び出し元の変数を
直接入れ替えることができます。呼び出しは swap(a, b) と変数をそのまま渡します。
なお、標準ライブラリにも同じ名前の std::swap() がありますが、
int& を引数に取る swap() を自分で定義しているので、こちらが優先して呼ばれます。
（実際のプログラムでは、<utility> の std::swap() を使うのが一般的です）


================================================================
問題 1-4　構造体とbool型
------------------------------------------------------------------
【解答】
#include <iostream>
#include <string>

using namespace std;

//    学生の構造体
struct Student{
    string name;    //    名前
    int score;      //    点数
};

//    60点以上なら合格（true）を返す
bool isPassed(Student& s)
{
    return s.score >= 60;
}

int main(){
    //    C++では、structを付けずに構造体の変数を宣言できる
    Student students[] = {
        { "山田", 75 },
        { "佐藤", 52 },
        { "鈴木", 60 },
        { "田中", 38 }
    };
    int count = 0;    //    合格者数

    for(int i = 0; i < 4; i++){
        cout << students[i].name << " : " << students[i].score << "点 ";
        if(isPassed(students[i])){
            cout << "合格" << endl;
            count++;
        }else{
            cout << "不合格" << endl;
        }
    }
    cout << "合格者数 : " << count << "人" << endl;
    return 0;
}

【解説】
C言語では、構造体の変数を宣言するときに struct Student s; のように struct を付けるか、
typedef で別名を付ける必要がありました。C++では、構造体の名前がそのまま型名として使えるので、
Student students[4]; のように struct を付けずに宣言できます。
また、構造体のメンバには、C言語の char 配列ではなく string 型を使うことができます。
bool 型は true（真）と false（偽）の2つの値だけを取る型です。
isPassed() は比較の結果 s.score >= 60 をそのまま返しており、if 文の条件にそのまま使えます。
構造体を関数に渡すときは、参照（Student&）にすると、構造体全体をコピーせずに済みます。
（応用編2日目で学ぶ const を使って const Student& とすると、関数の中で
　値を変更しないことも明示できます）
