開発環境：Visual Studio Code

Windows・macOS・Linux で C++ のプログラムを作成・実行する

トップページ › 開発環境：Visual Studio Code

Visual Studio Code とは

VSCode の特徴

Visual Studio Code（VSCode）は、Microsoft が開発している無料の軽量コードエディタです。Windows・macOS・Linux のすべてに対応しており、拡張機能を追加することで、さまざまな言語の開発環境として使えます。

C++ で VSCode を使う場合に必要なもの

VSCode はエディタなので、それだけでは C++ のプログラムをコンパイルできません。以下の 3 つをそろえる必要があります。

  1. Visual Studio Code（エディタ本体）
  2. C++ コンパイラ（g++ または clang++）
  3. C/C++ 拡張機能（VSCode 上でのコード補完・エラー表示・デバッグ支援）
💡 Windows だけで学習するなら、インストールするだけで C++ のコンパイラまでそろう Visual Studio 2026 のほうが手軽です。macOS や Linux を使っている人や、軽いエディタで学習したい人は、このページの手順で環境を作りましょう。

インストール

手順1：Visual Studio Code のインストール

以下の公式サイトから VSCode をダウンロードしてインストールします。

VSCode 公式サイト：https://code.visualstudio.com/

インストールオプションは基本的にデフォルトのままで問題ありません。Windows の場合は「PATH への追加」にチェックが入っていることを確認しておきましょう。

手順2：C++ コンパイラのインストール

使っている OS に合わせて、C++ コンパイラをインストールします。

Windows の場合（MSYS2 の MinGW-w64）

MSYS2 の公式サイトからインストーラーをダウンロードして実行します。インストールが終わったら、スタートメニューから MSYS2 UCRT64 を起動し、次のコマンドを実行します。

MSYS2 UCRT64
pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain

次に、Windows の環境変数 Path に C:\msys64\ucrt64\bin を追加します（インストール先を変えた場合は、そのフォルダーの ucrt64\bin を指定します）。

macOS の場合

ターミナルで次のコマンドを実行し、コマンドラインデベロッパツールをインストールします。clang++ が使えるようになります。

ターミナル
xcode-select --install

Linux（Ubuntu など）の場合

ターミナル
sudo apt update
sudo apt install build-essential

インストールできたら、新しく開いたターミナル（コマンドプロンプト）で次のコマンドを実行します。バージョン番号が表示されれば成功です（macOS では clang++ --version）。

ターミナル
g++ --version
⚠️ 「コマンドが見つかりません」と表示される場合は、Path の設定を確認し、ターミナルや VSCode を開き直してから、もう一度試してください。

手順3：C/C++ 拡張機能のインストール

VSCode を起動し、左側のアクティビティバーにある 拡張機能 アイコンをクリックします。検索欄に 「C/C++」 と入力し、Microsoft 製の C/C++（または関連する拡張機能をまとめた C/C++ Extension Pack）をインストールします。

プログラムの作成と実行

フォルダーを開く

Step 1

サンプルごとに作業用のフォルダー（例：Sample101）を作り、VSCode のメニューの ファイル → フォルダーを開く で開きます。

Step 2

エクスプローラーの「新しいファイル」アイコンで main.cpp を作成し、プログラムを入力して保存します。

main.cpp
#include <iostream>

using namespace std;

int main(){
    cout << "HelloWorld." << endl;
    return 0;
}

ターミナルでコンパイル・実行する

メニューの ターミナル → 新しいターミナル でターミナルを開き、次のコマンドでコンパイルします。-o main は、できあがる実行ファイルの名前の指定です。

ターミナル
g++ -o main main.cpp

エラーが出なければ、実行ファイルができています。次のコマンドで実行します。

ターミナル（Windows）
.\main.exe
ターミナル（macOS・Linux）
./main
実行結果
HelloWorld.

複数のファイルからなるプログラム

2日目以降のサンプルのように、ひとつのプログラムが sample.h・sample.cpp・main.cpp などの複数のファイルに分かれている場合は、.cpp ファイルをすべて 指定してコンパイルします。ヘッダファイル（.h）は、#include で読み込まれるので指定は不要です。

ターミナル
g++ -o main main.cpp sample.cpp
💡 C/C++ 拡張機能をインストールすると、エディタ右上に実行ボタン（▷）が表示されます。手軽ですが、標準の設定では開いているファイルだけをコンパイルするため、複数のファイルからなるプログラムでは「未定義の参照（undefined reference）」エラーになります。その場合は、上のようにターミナルでコンパイルしてください。
⚠️ Windows で日本語が文字化けする場合：ソースファイルは UTF-8 で保存されますが、コマンドプロンプトの標準の文字コードは Shift_JIS（CP932）です。実行する前にターミナルで chcp 65001 を実行して表示を UTF-8 に切り替えるか、g++ -fexec-charset=CP932 -o main main.cpp のように、実行ファイル側の文字コードを指定してコンパイルしてください。
