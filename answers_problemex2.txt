練習問題（応用編）2：クラス間の相互参照　解答と解説
================================================================


問題 2-1　クラスの相互参照
------------------------------------------------------------------
【解答】
// bar.cpp
#include "bar.h"
#include "foo.h"
#include <iostream>

using namespace std;

void Bar::func1(Foo* pFoo)
{
    pFoo->hoge();
}
void Bar::func2()
{
    cout << "Bar::func2()" << endl;
}

// foo.cpp
#include "foo.h"
#include "bar.h"
#include <iostream>

using namespace std;

void Foo::hoge(){
    cout << "Foo::hoge()" << endl;
}
void Foo::fuga(Bar* pBar){
    cout << "Foo::fuga()" << endl;
    pBar->func2();
}

// main.cpp
#include "foo.h"
#include "bar.h"
#include <iostream>

using namespace std;

int main(){
    Foo* pFoo = new Foo();
    Bar* pBar = new Bar();
    pFoo->hoge();        //    Foo::hoge()
    pBar->func2();        //    Bar::func2()
    pFoo->fuga(pBar);    //    Foo::fuga() → Bar::func2()
    pBar->func1(pFoo);    //    Foo::hoge()
    delete pBar;
    delete pFoo;
    return 0;
}

（bar.h、foo.h は問題文のまま。変更なし）

【解説】
ヘッダファイルでは「class Foo;」のような前方宣言だけをしているので、
ポインタの型として使うことはできますが、メンバ関数を呼び出すことはできません。
そのため、元のプログラムでは pFoo->hoge() や pBar->func2() の行でビルドエラーになります。
メンバ関数を呼び出すソースファイルの側で、相手のクラスのヘッダファイルを
インクルードすれば解決します。
  ・bar.cpp：Foo のメンバ関数を呼ぶので foo.h をインクルード
  ・foo.cpp：Bar のメンバ関数を呼ぶので bar.h をインクルード
ヘッダファイル同士で互いにインクルードし合うと循環してしまうので、
「ヘッダファイルでは前方宣言、ソースファイルでインクルード」が相互参照の基本です。
main.cpp では、インスタンスを生成して、期待される実行結果の順に関数を呼び出します。
new で生成したインスタンスは、最後に delete で消去しておきましょう。


================================================================
問題 2-2　constメンバ関数
------------------------------------------------------------------
【解答】
// rectangle.h
#ifndef RECTANGLE_H
#define RECTANGLE_H

//    長方形クラス
class Rectangle{
private:
    //    幅
    int m_width;
    //    高さ
    int m_height;
public:
    //    コンストラクタ
    Rectangle(int width, int height);
    //    大きさを変更する
    void setSize(int width, int height);
    //    幅を取得
    int getWidth() const;
    //    高さを取得
    int getHeight() const;
    //    面積を取得
    int getArea() const;
};

#endif // RECTANGLE_H

// rectangle.cpp
#include "rectangle.h"

//    コンストラクタ
Rectangle::Rectangle(int width, int height) : m_width(width), m_height(height)
{
}
//    大きさを変更する
void Rectangle::setSize(int width, int height)
{
    m_width = width;
    m_height = height;
}
//    幅を取得
int Rectangle::getWidth() const
{
    return m_width;
}
//    高さを取得
int Rectangle::getHeight() const
{
    return m_height;
}
//    面積を取得
int Rectangle::getArea() const
{
    return m_width * m_height;
}

（main.cpp は問題文のまま。変更なし）

【解説】
showRectangle() の引数 r は const の参照なので、関数の中では r を変更できません。
そのため、r からは「メンバ変数を変更しないことが保証されたメンバ関数」、
つまり const メンバ関数しか呼び出せず、getWidth() などを呼んだ行がビルドエラーになります。
メンバ変数の値を読み出すだけの getWidth()・getHeight()・getArea() の3つに、
宣言（rectangle.h）と定義（rectangle.cpp）の両方で、引数リストの後ろに const を付けます。
setSize() はメンバ変数を変更するので、const を付けることはできません。
（付けると、関数の中の m_width = width; がビルドエラーになります）
値を読み出すだけのメンバ関数には const を付けておくと、const のオブジェクトや
const の参照からも呼び出せるようになります。
