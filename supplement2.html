ファイルとストリーム

ファイルストリーム

基本編1日目で、cout や cin はストリームにデータを送り込んだり、受け取ったりするものだと説明しました。そして、ストリームの先はコンソールだけでなく、ファイルの場合もあると述べました（図1-3）。

C++ では、ファイルを読み書きするためのストリームとして、次のクラスが用意されています。いずれも、ヘッダ fstream をインクルードすると使えます。

表S2-1：ファイルを扱うストリームのクラス
クラス名用途コンソールで言えば
ofstreamファイルへの書き込み（output file stream）cout
ifstreamファイルからの読み込み（input file stream）cin
fstreamファイルの読み書きの両方—

これらのクラスは、cout や cin と同じように << や >> で読み書きできます。コンソールでの入出力を覚えていれば、ほとんど同じ書き方でファイルを扱えるのが、C++ のストリームの利点です。

ファイルへの書き込み

サンプルプログラム

まずは、テキストファイルに文字列を書き込んでみましょう。

lists2-1：main.cpp
#include <iostream>
#include <fstream>

using namespace std;

int main(){
    //    書き込み用にファイルを開く
    ofstream ofs("memo.txt");
    if (!ofs){
        cout << "ファイルを開けませんでした" << endl;
        return 1;
    }
    //    coutと同じように << で書き込む
    ofs << "C++のファイル入出力" << endl;
    ofs << "1 + 2 = " << 1 + 2 << endl;
    cout << "memo.txtに書き込みました" << endl;
    return 0;
}    //    ofsのデストラクタで、ファイルは自動的に閉じられる
実行結果
memo.txtに書き込みました
memo.txt の内容
C++のファイル入出力
1 + 2 = 3

プログラムを実行すると、実行したフォルダ（Visual Studio の場合はプロジェクトのフォルダ）に memo.txt が作られます。

ファイルを開く

8行目で、ofstream クラスのオブジェクト ofs を作っています。コンストラクタにファイル名を渡すと、そのファイルが書き込み用に開かれます。ファイルがなければ新しく作られ、すでにある場合は中身が消去されてから書き込まれます。

書き込み用にファイルを開く
ofstream 変数名("ファイル名");

フォルダが存在しないなどの理由でファイルを開けなかった場合に備えて、9行目で確認しています。ストリームのオブジェクトは、正常な状態なら true、エラーの状態なら false として扱えるので、!ofs が true ならファイルを開けなかったことがわかります。

書き込みとファイルを閉じる処理

14行目・15行目のように、cout と同じく << でファイルに書き込めます。endl で改行できる点も同じです。

C言語では、最後に fclose() でファイルを閉じる必要がありました。C++ の ofstream は、デストラクタでファイルを自動的に閉じます。このサンプルでは、main() を抜けて ofs が消去されるときに、ファイルが閉じられます。補講1で学んだように、例外が起きた場合もデストラクタは呼ばれるので、ファイルの閉じ忘れが起きません。

ファイルからの読み込み

1行ずつ読み込む

続いて、先ほど作った memo.txt を読み込んで、1行ずつ表示してみましょう。lists2-1 と同じフォルダで実行してください。

lists2-2：main.cpp
#include <iostream>
#include <fstream>
#include <string>

using namespace std;

int main(){
    //    読み込み用にファイルを開く
    ifstream ifs("memo.txt");
    if (!ifs){
        cout << "ファイルを開けませんでした" << endl;
        return 1;
    }
    //    1行ずつ読み込んで表示する
    string line;
    int count = 0;
    while (getline(ifs, line)){
        count++;
        cout << count << "行目：" << line << endl;
    }
    return 0;
}
実行結果
1行目：C++のファイル入出力
2行目：1 + 2 = 3

9行目で、ifstream クラスのオブジェクトを作り、memo.txt を読み込み用に開いています。

17行目の getline() は、ストリームから1行分の文字列を読み込み、第2引数の string に入れる関数です。行末の改行文字は含まれません。読み込みに成功すると、getline() の戻り値（ストリーム）は true として扱われ、ファイルの終わりに達して読み込めなくなると false になります。そのため、このように while 文の条件に書くと、ファイルの最後の行まで順に処理できます。

ファイルを1行ずつ読み込む
string line;
while (getline(ifs, line)) {
1行分の処理
}

データを区切って読み込む

cin と同じように >> を使うと、空白や改行で区切られたデータを1つずつ読み込めます。次のような内容のファイル score.txt を用意して、サンプルを実行してみてください。

score.txt の内容
Tom 80
Bob 66
Mike 92
lists2-3：main.cpp
#include <iostream>
#include <fstream>
#include <string>

using namespace std;

int main(){
    ifstream ifs("score.txt");
    if (!ifs){
        cout << "ファイルを開けませんでした" << endl;
        return 1;
    }
    string name;
    int score;
    int total = 0, count = 0;
    //    「名前 点数」の形式で、1件ずつ読み込む
    while (ifs >> name >> score){
        cout << name << "：" << score << "点" << endl;
        total += score;
        count++;
    }
    if (count > 0){
        cout << "平均：" << static_cast<double>(total) / count << "点" << endl;
    }
    return 0;
}
実行結果
Tom：80点
Bob：66点
Mike：92点
平均：79.3333点

17行目の ifs >> name >> score で、名前（文字列）と点数（整数）を1件分読み込んでいます。読み込む変数の型に合わせて自動的に変換されるのは、cin の場合と同じです。ファイルの終わりに達するか、点数の位置に数値以外が書かれていると読み込みに失敗し、ループが終わります。

ファイルを開くモード

追記モード

ofstream でファイルを開くと、通常は元の内容が消去されます。元の内容を残したまま、後ろに書き足したい場合は、追記モードで開きます。

lists2-4：main.cpp
#include <iostream>
#include <fstream>
#include <string>

using namespace std;

int main(){
    string text;
    cout << "記録する文字列を入力：";
    cin >> text;
    //    追記モードで開く（元の内容の後ろに書き足す）
    ofstream ofs("log.txt", ios::app);
    if (!ofs){
        cout << "ファイルを開けませんでした" << endl;
        return 1;
    }
    ofs << text << endl;
    ofs.close();    //    明示的に閉じることもできる
    //    ファイルの中身を確認する
    ifstream ifs("log.txt");
    string line;
    cout << "--- log.txtの内容 ---" << endl;
    while (getline(ifs, line)){
        cout << line << endl;
    }
    return 0;
}
実行結果（1回目）
記録する文字列を入力：apple← キーボードから入力
--- log.txtの内容 ---
apple
実行結果（2回目）
記録する文字列を入力：banana← キーボードから入力
--- log.txtの内容 ---
apple
banana

12行目のように、ファイル名の後ろに ios::app を指定すると、追記モードでファイルが開かれます。実行するたびに、入力した文字列が log.txt の末尾に追加されていきます。

また、18行目のように close() メンバ関数を呼ぶと、デストラクタを待たずにファイルを閉じられます。ここでは、書き込んだ内容をすぐに読み込んで確認するために、先に閉じています。

主なモード

ファイルを開くときに指定できる主なモードは、次のとおりです。| でつなげて、複数指定することもできます（例：ios::out | ios::app）。

表S2-2：ファイルを開く主なモード
モード意味
ios::in読み込み用に開く（ifstream の標準）
ios::out書き込み用に開く（ofstream の標準）
ios::app追記モード。書き込みは常にファイルの末尾に行われる
ios::trunc開くときに、元の内容を消去する
ios::binaryバイナリモード。改行文字の変換などを行わない
⚠️ Windows で日本語を含むファイルを読み書きする場合、ソースファイルやテキストファイルの文字コード（UTF-8 か Shift_JIS か）がそろっていないと、文字化けすることがあります。文字化けしたときは、まず文字コードを確認してください。
